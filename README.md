# FilmCraft iPhone HDR — 0.7.2-iphone-hdr.9

Независимый форк [FilmCraft](https://github.com/storytold/filmcraft) для монтажа видео с iPhone на Mac с Apple silicon: HDR-предпросмотр, экспорт Dolby Vision, русский текст из речи и короткие субтитры. Основа — upstream **v0.7.2**, коммит [`71438c627b5cbcfb550526c3971f4d0037733c5c`](https://github.com/storytold/filmcraft/commit/71438c627b5cbcfb550526c3971f4d0037733c5c).

Это самостоятельная модификация, не официальный релиз ArtCraft. Номер пакета в Cargo остаётся `0.7.2`; локальный упаковщик устанавливает версию приложения `0.7.2-iphone-hdr.9`.

**В репозитории опубликованы исходники и инструкции. Готовый бинарный релиз для этой публикации не собирался.** Последние объединённые изменения Dolby Vision, вертикального видео и субтитров не проходили сборку или тесты по запросу владельца. Наличие кода не означает, что работа всех сценариев уже подтверждена.

## Что изменено

### HDR и Dolby Vision

- Добавлена нативная поверхность macOS EDR с плавающей точкой для мониторов Source и Program. Яркость адаптируется к доступному запасу яркости дисплея.
- HDR определяется по исходному файлу. Предпросмотр использует оригинал, обходя SDR-прокси и SDR-кеш предпросмотра.
- Новая последовательность из HLG/PQ-видео наследует его HDR-пространство. Первый HDR-клип в пустой стандартной Rec.709-последовательности также включает HDR. Уже смонтированные последовательности и явно выбранные пространства сохраняются.
- Для HLG начальный экспорт настроен на **HEVC Main10, Dolby Vision Profile 8.4**; для PQ — на **HEVC HDR10**. Размер и частота кадров берутся из последовательности.
- Apple VideoToolbox создаёт новые Dolby Vision-метаданные по итоговым кадрам монтажа. Экспорт требует настоящий профиль 8.4 и запись `dvvC`; при отсутствии поддержки возвращается ошибка без скрытой замены результата на SDR или обычный HLG.
- Сохраняются исходные метаданные окружения `amve`. При конфликте известных окружений выводится ошибка; при отсутствии `amve` используется 314 lux, D65.

Для монтажа iPhone Dolby Vision используется его совместимый базовый слой HLG. Исходные динамические метаданные камеры не копируются на изменённые кадры: они формируются заново при экспорте.

### Вертикальное видео с iPhone

- Размер учитывает ориентацию отображения файла: портретное видео определяется как **1080 × 1920**, даже если закодированный кадр хранится как 1920 × 1080 с поворотом.
- Первый видеоклип в пустой последовательности стандартного размера задаёт её холст и пропорции пикселя. Если последовательность ещё не редактировалась, частота кадров также берётся из исходника до расчёта размещения; существующий аудиомонтаж сохраняет свою временную базу.
- Новая последовательность из подклипа получает размеры и частоту кадров исходного медиа; точка привязки также учитывает исходный размер.
- Для старого горизонтального проекта с вертикальным видео: выделить видеоклип и выбрать **Sequence → Match Frame Size to Source / Размер кадра по исходнику**.
- Эта команда меняет размер холста и положение его центра, сохраняя масштаб Motion, время клипов и HDR-настройки. Ранее вручную введённый размер экспорта сбрасывается на Match Source; кодек и другие параметры сохраняются. Операцию можно отменить.
- Пользовательский зум, обрезка эффектами и анимация остаются как были: команда не отменяет сделанное вручную кадрирование.

### Субтитры из транскрипции

- Перед генерацией можно выбрать **максимум слов в строке: 1–100** и **строк в блоке: 1 или 2**. По умолчанию — **3 слова, 1 строка**. Успешно использованные настройки запоминаются.
- Указанное число — верхний предел. На конце предложения блок заканчивается раньше: учитываются точки, многоточия, вопросительные/восклицательные знаки и закрывающие кавычки.
- После определения границ текст переводится в **ВЕРХНИЙ РЕГИСТР**, знаки препинания удаляются. Поддерживается Unicode, включая русский; токены только из пунктуации не считаются словами.
- Ограничения работают и для вручную исправленных записей транскрипции, содержащих несколько слов. Их существующие временные границы используются при разбиении.
- Исходная транскрипция и уже отредактированный вручную текст субтитров не переписываются. Генерация создаёт новую дорожку, сохраняя предыдущие.
- Поля начала и конца больше не теряют набранный текст при уходе фокуса. **Apply / Enter** применяет обе границы одной отменяемой операцией; **Cancel / Escape** отменяет ввод. Ошибочный таймкод или пересечение показывают ошибку и сохраняют черновик.
- Формат таймкода — **HH:MM:SS:FF**: последние две цифры обозначают кадры, а не доли секунды.

### Вид и положение субтитров

- Новые дорожки получают **Roboto Black Italic** с кириллицей, непрозрачную белую заливку, чёрную обводку 3 px и смещённую объёмную тень −4/+5 px при высоте кадра 1080. Прямоугольный Box по умолчанию выключен.
- Это подобранный близкий стиль к визуальному образцу, а не достоверная идентификация шрифта на чужом изображении.
- **Reference style / Как на образце** применяет оформление к существующей дорожке, сохраняя её размер текста и положение. Старые сохранённые стили сами по себе сохраняют прежнее начертание и эффекты.
- Семейство и начертание шрифта, **Box**, чёрная обводка и объёмная тень доступны независимо. Элементы стиля переносятся на две строки в узкой панели.
- Рядом с Top / Middle / Bottom добавлено числовое вертикальное положение: **0 / 50 / 100 %** соответствуют верхней безопасной границе, центру и нижней безопасной границе. Можно ввести промежуточное значение.
- Ручное положение переопределяет импортированное положение cue. Старые проекты без нового значения сохраняют прежние правила привязки и VTT.
- **Белый HDR / HDR white** отдельно регулирует яркость букв от **100 до 1000 нит**. По умолчанию — **1000 нит**, в том числе для старых дорожек без этого поля. Значение 203 нит соответствует стандартному опорному белому, но выглядит менее ярким рядом со светлыми HDR-областями.
- Меняется только RGB заливки букв; прозрачность, обводка, тень, Box, яркость самого видео и SDR-экспорт не меняются. Предпросмотр ограничивает яркость доступными возможностями дисплея.
- В EDR-предпросмотре субтитры накладываются после преобразования яркости видео. При HDR-экспорте их цвета переводятся из BT.709 в рабочее пространство с выбранной яркостью белого.

### Таймлайн и экспорт

- Выделение рамкой захватывает субтитры вместе с видео и аудио. Перетаскивание тела любого выделенного блока перемещает всю группу на общий интервал, с предпросмотром и одним шагом отмены.
- Shift добавляет к выделению; Escape восстанавливает выделение или отменяет перетаскивание. Границы последовательности, соседние субтитры и заблокированные дорожки учитываются совместно, чтобы элементы не расходились по времени.
- Копирование дублирует и выбранные субтитры. При вставке они не получают повторный сдвиг. Недопустимое пересечение отклоняет всю операцию, не оставляя частично перемещённую группу.
- При наличии дорожки субтитров **Burn Captions Into Video** включается по умолчанию, включая Quick Export и очередь со встроенными пресетами.
- Ручной выбор сохраняется при обновлении окна и смене формата. Пользовательские пресеты и явно выбранные отдельные файлы субтитров сохраняют собственные настройки.

## Требования

- Mac с **Apple silicon (arm64)**. Специальный упаковщик этой ветки не предназначен для Intel, Windows или Linux.
- **macOS 12 или новее** и поддерживаемое Apple-оборудование для экспорта Dolby Vision. Для полноценного HDR-предпросмотра нужен дисплей с доступным EDR/HDR.
- **Rust 1.95 или новее**, Cargo, Git и Xcode Command Line Tools.
- Интернет для первоначального получения исходников, зависимостей, шрифтов и весов Whisper. После скачивания модели распознавание работает локально.

Если инструменты ещё не установлены:

```bash
xcode-select --install
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
```

В установщике Rust выбрать стандартную установку — Enter. Затем в том же терминале:

```bash
source "$HOME/.cargo/env"
rustup update stable
rustup default stable
```

Для нового рабочего каталога:

```bash
cd "$HOME/Documents"

bash packaging/macos/prepare-iphone-fonts.sh
```

Для чтения публичного репозитория без настроенного SSH вместо SSH-адреса можно использовать `https://github.com/user14052020/filmcraft.git`. Если `FilmCraft-STT` уже существует, выберите другое имя для нового клона. Старый клон `storytold/filmcraft` с локальными изменениями не обновляется обычным `git pull` из этого форка; сохраните его отдельно.

Шрифты хранятся отдельно от этого репозитория. Подготовщик создаёт соседний каталог `../craft-fonts`, получает [storytold/craft-fonts](https://github.com/storytold/craft-fonts) на ревизии `3d9ab3a132ed0eff457e424226a435a901da30d3` и добавляет статический Roboto Black Italic из официального [googlefonts/roboto-2](https://github.com/googlefonts/roboto-2/tree/38062f4b4a0be4346d07a928408da21602545e9e).

Файл закреплён за ревизией `38062f4b4a0be4346d07a928408da21602545e9e`; SHA-256:

```text
5ac072b1f16adecb9ab44891f756bd689b5760a02c0c1b14f9b7afe2f68ebbe9
```

Подготовщик проверяет хеш, добавляет запись в манифест, лицензию Apache-2.0 и атрибуцию. Существующий каталог craft-fonts не сбрасывается на другую ревизию; конфликтующий файл или запись манифеста вызывает ошибку. Скрипт не собирает и не устанавливает FilmCraft.

Другой каталог можно задать переменной `CRAFT_FONTS_DIR`; используйте её и при подготовке, и при сборке:

```bash
export CRAFT_FONTS_DIR="$HOME/Documents/craft-fonts"
bash packaging/macos/prepare-iphone-fonts.sh
```

## Сборка, установка и обновление

Только собрать пакет приложения:

```bash
cd "$HOME/Documents/FilmCraft-STT"
bash packaging/macos/build-iphone-hdr.sh
```

Результат: `dist/release/FilmCraft-iPhone-HDR.app`; CLI: `target/release/filmcraft-cli` при стандартных путях вывода.

Для сборки и замены установленного приложения сначала сохранить проект и закрыть FilmCraft:

```bash
cd "$HOME/Documents/FilmCraft-STT"
bash packaging/macos/build-iphone-hdr.sh --install
```

После успешной сборки и локальной ad-hoc подписи старое `/Applications/FilmCraft.app` перемещается в Корзину, новое устанавливается на его место. Это локально подписанная сборка, не нотарифицированный разработчиком дистрибутив. Исходное видео, проекты, пользовательские настройки и уже скачанные модели скрипт не изменяет.

Для обновления клона **этого репозитория** без конфликтующих локальных правок:

```bash
cd "$HOME/Documents/FilmCraft-STT"
git pull --ff-only
bash packaging/macos/prepare-iphone-fonts.sh
bash packaging/macos/build-iphone-hdr.sh --install
```

Упаковщик встраивает подготовленные шрифты через `CRAFT_FONTS_DIR`, копирует их лицензии и сохраняет распознавание речи в GUI и CLI. Его команда компиляции:

```bash
cargo build --release --locked -p filmcraft -p filmcraft-cli \
  --features filmcraft/whisper,filmcraft-cli/whisper
```

## Распознавание русского языка: что и куда добавлено

Используется готовая многоязычная модель **OpenAI Whisper**. Мы не обучали новую модель: включили существующую интеграцию FilmCraft, которая в стандартной конфигурации Cargo выключена, и подключили скачиваемые официальные веса.

Цепочка возможностей: `filmcraft/whisper` и `filmcraft-cli/whisper` включают `filmcraft-engine/whisper` и `filmcraft-engine/speech-download`; библиотека `filmcraft-speech` выполняет распознавание через **Candle на CPU**. Это не облачный API; ключ OpenAI не нужен. Аудио подаётся в движок как mono 16 kHz, а результат содержит времена отдельных слов. Исходный видеофайл при этом не преобразуется и не перезаписывается.

По умолчанию используется **whisper-base**, 74 млн параметров, около 293 MB файлов. Есть также `whisper-tiny` и `whisper-small`; все три варианта многоязычные и поддерживают русский. Англоязычный вариант `.en` не нужен.

После сборки скачать модель один раз:

```bash
./target/release/filmcraft-cli exec transcript.downloadModel model=whisper-base
./target/release/filmcraft-cli exec transcript.models
```

Официальный источник — [openai/whisper-base на Hugging Face](https://huggingface.co/openai/whisper-base). В каталоге FilmCraft закреплена ревизия `e37978b90ca9030d5170a5c07aadb050351a65bb`; загрузчик проверяет SHA-256 каждого нового файла перед установкой.

На macOS стандартное хранилище модели:

```text
~/Library/Application Support/FilmCraft/models/whisper-base/
├── config.json
├── generation_config.json
├── tokenizer.json
└── model.safetensors
```

Именно такой набор установлен на Mac, на котором готовилась эта версия. После скачивания распознавание работает без интернета; звук обрабатывается локально. Веса не вшиты в `.app` и не добавлены в Git: они скачиваются отдельно и сохраняются при замене приложения. Переменная `FILMCRAFT_DATA_DIR` меняет базовый каталог данных; тогда путь — `$FILMCRAFT_DATA_DIR/models/whisper-base/`. `FILMCRAFT_MODELS_DIR` относится к тестовым сценариям, а не к обычному запуску приложения.

**Для русского языка нужно выбрать настройку явно:** исходные настройки нового профиля — English, автоопределение выключено.

1. Открыть **Settings → Media Analysis & Transcription / Анализ медиа и расшифровка**.
2. В **Speech model** выбрать **Whisper base**.
3. В **Default language** выбрать **Russian**. Для принудительного русского оставить **Enable language auto-detection** выключенным; для автоматического выбора языка — включить.
4. Открыть **Text → Transcript → Transcribe**, затем создать дорожку субтитров из транскрипции.

В CLI язык можно задать независимо от настроек:

```bash
./target/release/filmcraft-cli --project "/path/to/project.fcproj" \
  exec transcript.generate model=whisper-base language=ru --save
```

`language=auto` включает автоопределение для конкретного вызова. Без `items` распознаются выбранные элементы проекта, а при отсутствии выбора — исходники активных аудиоклипов последовательности. Существующие предпочтения модели и языка остаются в каталоге данных FilmCraft.

## Ограничения и статус проверки

- После монтажа видео кодируется заново: это не побитовая копия исходника и не перенос исходных Dolby Vision-метаданных без изменений.
- HDR-композиция с плавающей точкой сейчас использует CPU и может работать медленнее SDR. Распознавание Whisper также выполняется на CPU.
- Режимы сравнения/просмотра каналов и PNG-скриншоты остаются SDR. Внешний проигрыватель или сервис может самостоятельно преобразовать HDR.
- Более ранние HDR-компоненты собирались при разработке, но полная текущая версия с последними правками не была собрана и протестирована. При публикации новые сборки и проверки не запускались.
- GitHub Actions настроены на ручной запуск: push сам по себе не запускает сборку. Бинарный GitHub Release для этой публикации не создавался.
- Изменения исходников начинают действовать после пересборки. Чтобы увидеть исправления экспорта, необходимо экспортировать проект заново; существующие видеофайлы не изменятся.

Roboto Black Italic — Google / Christian Robertson, **Apache-2.0**; лицензия и происхождение находятся в [`packaging/fonts/`](packaging/fonts/) и копируются в приложение. Новые файлы шрифта остаются во внешнем craft-fonts, а не в этом Git-репозитории.

Whisper: веса OpenAI — **MIT**, опубликованная Hugging Face-конверсия — **Apache-2.0** согласно модельному каталогу. Веса загружаются из официальных источников. Остальные атрибуции — [`ATTRIBUTION.md`](ATTRIBUTION.md).

Логотипы ArtCraft удалены из публикуемой модификации в соответствии с [условиями товарных знаков](docs/brand/LICENSE-brand.txt). Авторство исходного проекта сохранено; одобрение этой версии командой upstream не подразумевается.

Вопросы по этой версии: [Issues](https://github.com/user14052020/filmcraft/issues). Исходный проект: [storytold/filmcraft](https://github.com/storytold/filmcraft).
